# Python---aprendizado-de-m-quina-

Exemplo em Python de uma **Máquina de Helmholtz** treinada com o algoritmo **Wake-Sleep**.

## Arquivo principal
- `helmholtz_machine.py`: implementação didática com dados sintéticos binários (barras 8x8).

## Como executar
```bash
python3 helmholtz_machine.py
```
